Thực Hành Các Cách Nhúng CSS Vào HTML

1. Tiêu đề sử dụng Inline Style

Đoạn văn này được định dạng màu sắc trực tiếp qua thuộc tính style inline trên thẻ p.

2. Tiêu đề sử dụng Internal Style

Đoạn văn này nhận màu sắc và phông chữ từ bộ chọn class được khai báo trong thẻ <style> ở phần <head>.

3. Tiêu đề sử dụng External Style

Đoạn văn này được định dạng màu sắc từ file stylesheet độc lập bên ngoài (style.css).
